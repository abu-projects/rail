# RAIL public catalog API

GET https://railcycles.ch/api/catalog returns the public models, frame guide prices (CHF, excluding VAT), specifications and bilingual page links as JSON. No authentication is required. Prices are guides, not quotes; confirm with Sam using the website contact page.

The read-only MCP endpoint is https://railcycles.ch/mcp. Its `get_rail_catalog` tool returns the same public data. No tool submits enquiries or orders.
