# Solar navigation arrow

`solar-arrow-right-up.svg` is Solar's **Arrow Right Up / Linear**, by 480 Design.
Source: https://github.com/480-Design/Solar-Icon-Set/blob/main/icons/SVG/Linear/Arrows/Arrow%20Right%20Up.svg

The path is unchanged. Presentation attributes add a CSS class, `currentColor`,
explicit dimensions and decorative accessibility attributes. The static site
generator embeds this local SVG, so navigation does not depend on an icon font,
JavaScript or a third-party CDN. Rotated variants use the same path.

# Social brand icons

`instagram.svg`, `facebook.svg`, `x.svg` and `tiktok.svg` come from
[Simple Icons](https://github.com/simple-icons/simple-icons/tree/develop/icons),
under CC0 (see `simple-icons-LICENSE.md`). Brand paths are unchanged; decorative
accessibility and presentation attributes are added for inline use. Each link
retains an accessible platform name and a tooltip.
