# Access to RAIL public information

No registration, account, API key or OAuth flow is required for the public website, GET https://railcycles.ch/api/catalog or the read-only MCP tool at https://railcycles.ch/mcp.

The only agent tool is `get_rail_catalog`. It reads published models, frame guide prices, specifications and page links. There are no protected agent APIs, personal account data, ordering tools or automated enquiry tools.

To make an enquiry, open https://railcycles.ch/en/contact and review the message before submitting. Sending an enquiry requires the person’s explicit approval.
